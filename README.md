# Fair Graph Learning Needs Expressiveness: Rethinking Fairness from the Spectral Perspective

Official implementation of **"Fair Graph Learning Needs Expressiveness: Rethinking Fairness from the Spectral Perspective"**, accepted by *ACM Transactions on Knowledge Discovery from Data (TKDD)*.

## Usage

The datasets and corresponding processing utilities are provided in `data/` and `dataset/`.

Experiment settings can be configured in:

```text
config.yaml
```

To run the model:

```bash
python main.py
```
